# NovelAI 4.5 角色参考（Character Reference）：一张图当 LoRA 用

> 来源：B 站「【NAI教程】一张图训练LoRA绘制自己喜欢的角色｜NovelAI 4.5 角色参考 教程」（UP：衡鲍，13:03）。正文结论全部来自视频画面与烧录字幕，字幕没提到的参数不补。

## 0. 先说结论：没有「训练」这回事

标题里的「一张图训 LoRA」是比喻。Character Reference 不训练权重、不产出 LoRA 文件，所以**没有训练参数、没有耗时、也没有触发词**。它做的是：每次生成时由内部模型现场分析参考图 → 提取一个外观向量（发色、发型、脸型、服装等）→ 直接注入当前采样流程。

对比传统 LoRA（视频里的原话逻辑）：SD 之类要「准备几十上百张图」「训练出新的权重修正矩阵」才能「长期复现」；Character Reference 是「每次都需要重新分析」，换来一张图即改即用。

## 1. 入口与面板

- 打开 novelai.net/image，模型选 **NAI Diffusion V4.5 Full**（多角色演示那段用的是 V4.5 **Curated**，两个都能用）。
- 左侧提示词框下方有两个按钮：**Vibe Transfer**、**Character Reference**。点 Character Reference 弹出独立面板，把图拖进槽位；按钮上会显示缩略图。
- 面板内还有一个 **Style Aware** 开关（默认勾选）。作者的操作是**导入参考图后把它关掉**；字幕另有一句「平时大家生成时可以保持这个」，即不导参考图时开着即可。

## 2. 参考图怎么挑（作者给的规范，逐条）

- 不要出现多个角色或背景；
- 人物尽量完整；
- 不要有闭眼之类遮挡特征的动作；
- 背景可以是透明通道 PNG；
- 背景最好不要过于复杂；
- 分辨率用 NovelAI 预设里【大】档的三种之一：**1024×1536 / 1472×1472 / 1536×1024**；
- 构图对齐：目标图是上半身，就**只导入上半身立绘**（视频原话「则最好只导入上半身的立绘」）；
- 最好附上对应作品的风格。

视频演示里他同时放了全身、上半身、透明背景刘海特写几张，用来分别锁不同层级的特征。

## 3. 计费：按「每次生成」算

- Character Reference：**每次生成 +5 Anlas**（基础费用另算），幻灯片写的是「基础费用 + 5 Anlas / per generation」；
- **一次性导入 +2 Anlas**，之后每次生成 +5 Anlas；
- Img2Img、Vibe Transfer、Character Reference 三者的计费结构相同；
- 坑：字幕强调「而且是【每次生成】不是【每次导入】」——即便最高等级会员用户，也按生成次数扣。

## 4. 显性特征 vs 隐性特征

- Character Reference **只识别角色的显性特征**（看得见的：发色、发型、瞳孔、服装）；
- 「模型只能依据【看得见的信息】来生成」，表情、习惯这类看不见的部分它只能靠风格描述去猜；
- 正确做法：参考图管显性，**角色提示词补隐性**，「补充好后再次生成，则结合了角色的显性和隐性特征」。
- 另一个坑：细节「几乎会被主提示词内的风格完全覆盖」——主提示词里的风格词越重，参考图的瞳孔等细节越容易被吃掉。

## 5. 多角色 + 角色参考

- 右侧 **Character Prompt** 面板 → **Add a Character**，出现「角色 1」「角色 2」两个槽位（可继续加）。
- 主提示词写整体，视频里的写法：`[(two prompts: 1.5::1 girl and 1 boy 2-character), 1.2::standing by riverside, golden twilight background, reverse light, golden lights, wheats on the side of the river, ancient vibe.`
- 角色 1 / 角色 2 里分别写这个角色的显性 + 隐性特征（他用英文 tag，也演示了中文描述）。
- 槽位与参考图**一一对应**：slot 1 对应角色 1，slot 2 对应角色 2，不会自动错位——字幕原话「为 SLOT1 和 SLOT2 注入了基本的特征」。
- 主要坑：主提示词与角色提示词**共享语境**（都写了 two girls / girl / 同一风格），导致「AI 往往会犯 reference 的一部分特征」「长相像 a 和 b 的融合」，或者主提示词影响角色 1。
- 解法：**尽量分别描写**两个角色的显性与隐性特征，「减少共享语境造成的扩散」；要精准就**单独生成一次目标人物的单人图**，「细节还原更到位」。
- 补救手段：局部崩了用 **inpaint** 修（他演示时也翻车过，「但很不凑巧」）。

## 6. 数值速查

| 项目 | 值 |
|---|---|
| 参考图分辨率 | 1024×1536 / 1472×1472 / 1536×1024 |
| 参考图张数 | 多槽位（演示 3 张：全身 / 上半身 / 透明背景特写） |
| 参考强度 / 保真度滑杆 | 面板中未出现，视频未讲（不编） |
| 计费 | 导入 +2 Anlas 一次；每次生成 +5 Anlas |
| 模型 | NAI Diffusion V4.5 Full / Curated |

## 7. 角色一致性操作清单（5 条）

1. **一张干净的图**：单人、无复杂背景（或透明 PNG）、不闭眼、分辨率落在 1024×1536 / 1472×1472 / 1536×1024，构图与目标一致（要半身就给半身）。
2. **关掉 Style Aware 再导图**，主提示词里的风格词别压太重，否则参考图的瞳孔、发丝细节会被风格覆盖。
3. **参考图管显性、角色提示词管隐性**：把表情、年龄、服装材质、动作习惯这些「看不见的」写进角色提示词，再生成一次。
4. **多角色走 Character Prompt + Add a Character**：主提示词只写场景与构图，两个角色各自写特征；发现串味就把共享词删干净，必要时先单人生成确认细节。
5. **算好 Anlas**：导入只花 2，但每次生成 +5（基础费另算）——批量试错前先想清楚要抽几次。
